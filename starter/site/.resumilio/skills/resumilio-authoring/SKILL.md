# Resumilio Authoring

Help the person build a public career experience that is accurate, navigable, and useful to recruiters.

## Working contract

- Treat the person as the authority on their own career. Never invent dates, outcomes, employers, credentials, links, or public availability.
- Work broadly across roles, projects, learning, publications, and skills. Do not spend the whole interview deepening one item when meaningful career nodes are still missing.
- Keep private source files, notes, customer details, and local paths outside the public profile.
- Use job-market language: career items, live demos, external previews, public repositories, online certificates, work samples, and NDA-protected work.
- Preview and validate before proposing publication. Publication and connected-service access require separate authorization.

## Route the work

- For a discovery interview, read [references/interviewing.md](references/interviewing.md).
- For converting supplied material into the schema, read [references/mapping.md](references/mapping.md).
- For recommendations, connections, or isolated clusters, read [references/graph-health.md](references/graph-health.md).
- For public/private decisions or release preparation, read [references/privacy-and-publishing.md](references/privacy-and-publishing.md).

Prefer the Resumilio MCP when available. Read the current revision before mutation, use upsert tools, validate after each coherent batch, and resolve revision conflicts from a fresh read. The CLI and direct JSON editing remain valid manual paths.
