# Mapping content

Map identity and contact routes into `profile`, organizations into `organizations`, and each distinct role, project, course, certificate, publication, or skill into `careerItems`.

Use `resources` only for recruiter-useful availability:

- `live-demo`: an interactive running product.
- `external-preview`: a public marketplace page, article, case study, or product page.
- `public-repository`: source code intended for public review.
- `online-certificate`: an issuer-hosted or otherwise public credential.
- `work-sample`: a public artifact or downloadable result.
- `nda-protected`: useful work whose private implementation cannot be disclosed. Never attach a URL or private locator.

Localized fields must contain every configured locale. If a translation is not available, ask for it or draft it for explicit review. Keep stable kebab-case IDs when editing existing content.
