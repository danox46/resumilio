# Graph health and recommendation variety

Every career item must be reachable through the experience, even when the explicit semantic graph has more than one cluster. Prefer meaningful connections first, then add the smallest honest bridge between chapters of the career.

Validate both presentation sizes:

- Mobile promotes four surrounding items.
- Desktop promotes five surrounding items.

Avoid a lazy loop where the same valid neighborhood repeats forever. Review paths from the newest, oldest, and least-connected items. Each should expose at least one route outside its immediate cluster within a few selections. Maintain variety across item kinds and public availability without forcing irrelevant items.
