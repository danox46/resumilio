# Interviewing for career breadth

Start with an inventory before deep detail. Ask about:

- Current and previous roles, including older work that explains the path to the present.
- Products, internal tools, integrations, migrations, experiments, and downloadable work.
- Education, certifications, courses, talks, articles, communities, and recognitions.
- Work that cannot be linked publicly but can be described safely.

Capture one concise career item per distinct responsibility or outcome. Ask for organization, approximate dates, what changed because of the work, relevant skills, and whether a public resource exists. A public link is a bonus, not a condition for including real work.

When the inventory has coverage, revisit the most relevant items for clearer outcomes. Mark uncertainty explicitly and ask the person; never convert inference into fact.
