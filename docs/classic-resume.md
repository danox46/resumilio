# Classic resume presentation

The constellation's `Classic View` action opens one continuous bilingual resume:

- English: `/classic/#<claim-id>`
- Spanish: `/es/clasico/#<claim-id>`

Every graph claim is rendered as an anchored resume entry. The browser scrolls to the selected entry and CSS `:target` styling highlights it. Legacy per-claim routes remain only as redirects so existing links do not strand visitors; they are not content pages and are not listed in the sitemap.

The classic document uses semantic headings, sections, entries, contact links, and A4 print rules. A later PDF export can therefore print or render this same document without introducing a separate resume layout or file-hosting requirement.
