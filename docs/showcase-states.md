# Showcase states

Resumilio presents public availability as a bonus, not as a burden of proof. The constellation derives one primary showcase state for each career record:

- Professional role
- Live demo
- Public source
- External preview
- Certificate online
- NDA protected
- Private work context

The state affects the node accent and contributes a small, non-binding ranking signal. Repeating the same state receives a modest diversity penalty, while direct relationships, visitor intent, novelty, and the graph traversal guarantee remain stronger signals.

Public destinations stay external. Resumilio stores HTTPS links to demos, repositories, marketplace pages, credential pages, or professional profiles; it does not upload, proxy, or host certificates and work files. Restricted records never expose a private locator. `nda-protected` is an explicit claim tag and must not be inferred merely because a record is private.

This presentation layer is derived from the existing v1 profile contract, so it does not change public schemas, CLI input, MCP input, or machine-readable endpoints.
